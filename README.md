# Transmux — Project Saga

Convert YouTube videos, SoundCloud tracks, or local media files into any format you need. Embed cover art, trim segments, and publish results to a live showroom gallery.

---

## How It Works

**Paste a URL** or **upload a file** — Transmux grabs the media and lets you pick output format, quality, bitrate, resolution, and trim points. Once converted, you can preview it in-browser, download it, or publish it to the public showroom for others to see.

## What You Can Do

- Download YouTube videos as MP3, Opus, FLAC, or any audio format with the video's thumbnail embedded as cover art
- Convert local video files to any container (MP4, MKV, WebM) with custom codecs
- Extract audio tracks from video files
- Trim media by setting start and end timestamps
- Remux without re-encoding for instant, quality-preserving conversion
- Publish completed files to a shared gallery visible to everyone
- Preview audio and video directly in the browser before downloading

## Supported Formats

| Type | Formats |
|------|---------|
| Audio | MP3, WAV, OGG, AAC, FLAC, M4A, Opus |
| Video | MP4, MKV, WebM, MOV, AVI, FLV |
| Subtitle | SRT, VTT, ASS, SUB |

## Built With

React, Tailwind CSS, Express, FFmpeg, yt-dlp.
